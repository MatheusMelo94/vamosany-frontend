One structure

Five slots, always in this order. Only what goes inside changes.

  1. Page labelMono line: page name and one fact. The only small text above the title.
  2. Title + train markerYour “Título” when the file has one, otherwise the page name. The yellow marker slides in once; with reduced motion it just sits there.
  3. DekYour “Bajada” or first paragraph, 18px, grey.
  4. Body: notes column + main columnLeft 200px column for dates, facts, contacts. Main column up to 760px. Stacks on phone.
  5. Closing rowOne sentence and one yellow button, between two 2px black rules.
